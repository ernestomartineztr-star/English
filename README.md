# English A1–C2 Audio Library

Companion audio website for the English A1–C2 learning book.

- `index.html`: cover QR destination and library landing page.
- `lessons.json`: lesson-to-audio manifest.
- `audio/A1` through `audio/C2`: reserved folders for lesson recordings.

**Current status:** Website shell is ready. No audio recordings or lesson QR codes have been published yet. Add verified public audio URLs to `lessons.json` before generating QR codes.

Planned per-lesson assets: natural-speed dialogue, slow dialogue, vocabulary pronunciation, listening exercise, and shadowing practice.
